MAZ POCKET — v0.03 PHONE-FIRST UPDATE

NORMAL UPDATE FROM v0.02
1. Use Google Chrome on Android, or Chrome/Edge on a computer.
2. Open: https://mazos-site.vercel.app/maz-pocket/flasher/
3. Connect the Cardputer ADV by USB data cable.
4. Tap CONNECT & UPDATE v0.03.
5. Choose the Cardputer when the browser asks.
6. Leave the cable connected until the page says v0.03 FLASHED + VERIFIED.

IF IT CANNOT ENTER DOWNLOAD MODE
- Unplug the Cardputer.
- Hold G0 (upper-right).
- Plug USB back in while holding G0, then release it.
- Tap CONNECT & UPDATE again.

THAT IS ALL
- No Windows updater EXE.
- No COM port selection.
- No FIND button.
- No IP address.
- No host token for flashing.
- No M5Launcher boot-banner timing.
- No manual partition commands.

WHAT THE WEB FLASHER DOES
- Reads the LIVE ESP32 partition table from your Cardputer.
- Finds exactly one existing Launcher app partition labelled MAZ-Pocket.
- Refuses before writing if the v0.03 image does not fit that live partition.
- Downloads a full raw backup of the existing MAZ-Pocket partition first.
- Writes ONLY the MAZ-Pocket partition.
- Never full-erases the flash.
- Never writes the partition table, NVS/settings, M5Launcher, SD data, Bruce or sibling firmware.
- Reads v0.03 back and requires an exact SHA-256 match.
- If verification fails, it attempts an automatic rollback.
- If the older failed updater already damaged the v0.02 image header, a known-good physical-hardware-accepted v0.02 recovery image is available to the rollback path.

MAZPOCKET.LOCAL AFTER v0.03
- Put your phone and Cardputer on the same Wi-Fi.
- Open http://mazpocket.local
- It is the small status/control/diagnostics page, NOT the firmware writer.
- Status is visible immediately.
- Sensitive controls/config require the existing MAZ pairing token.
- Self-test includes speaker, mic, MAZ Host and a small non-destructive SD read/write check.
- Firmware button sends you to the safe online Web Serial flasher.
- If .local does not resolve, use the IP shown by Maz Pocket.

DEVICE
- Home: COMM / LOG / OPS.
- Ctrl+K: all utilities plus Snake / Hyperdrive / Beam.
- Helpful v0.02-style state-change reminders remain enabled.
- Ctrl+L: guarded M5Launcher hand-back.
