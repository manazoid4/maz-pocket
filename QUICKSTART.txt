MAZ POCKET — v0.03 PHONE-FIRST UPDATE

YOU NEED
- Your Cardputer ADV running Maz Pocket v0.02 under M5Launcher.
- The single file: maz-pocket-v0.03-phone-first.zip
- Google Chrome on Android, or Chrome/Edge on a computer.
- A USB data cable.

UPDATE v0.02 -> v0.03
1. Keep the ZIP downloaded on your phone/computer. Do NOT extract it.
2. Open: https://mazos-site.vercel.app/maz-pocket/flasher/
3. Tap CHOOSE MAZ POCKET ZIP and select maz-pocket-v0.03-phone-first.zip.
4. Wait for the page to say VERIFIED.
5. Connect the Cardputer ADV by USB data cable.
6. Tap CONNECT & UPDATE v0.03 and choose the Cardputer when the browser asks.
7. Leave the cable connected until the page says v0.03 FLASHED + VERIFIED.

IF IT CANNOT ENTER DOWNLOAD MODE
- Unplug the Cardputer.
- Hold G0 (upper-right).
- Plug USB back in while holding G0, then release it.
- Tap CONNECT & UPDATE again.

THAT IS ALL
- No Windows updater EXE.
- No COM port selection.
- No FIND button.
- No IP address.
- No host token for flashing.
- No M5Launcher boot-banner timing.
- No manual partition commands.
- Do not extract or edit the ZIP: the page rejects changed firmware/recovery hashes.

WHAT THE WEB FLASHER DOES
- Verifies the exact CI-approved v0.03 firmware SHA-256 and known-good v0.02 recovery SHA-256 before asking for USB access.
- Uses the ESP32-S3 ROM loader only; it does not upload the RAM flasher stub that caused trouble in the earlier updater path.
- Reads only the live 4KB ESP32 partition table from the Cardputer.
- Finds exactly one existing Launcher OTA app partition whose label starts with maz-pocket.
- Refuses before writing if v0.03 does not fit that live partition.
- Writes ONLY the Maz Pocket app partition.
- Never full-erases the flash.
- Never writes the partition table, NVS/settings, M5Launcher, SD data, Bruce or sibling firmware.
- Uses the ESP32 ROM flash-MD5 command to verify the written v0.03 image.
- If write/verification fails after a write starts, it attempts to restore the known-good physical-hardware-accepted v0.02 image and verifies that recovery by ROM MD5.

WHY THE ZIP IS SELECTED LOCALLY
- The Maz Pocket source repository is private.
- The online flasher therefore contains no GitHub token and does not make the repo public.
- The page only accepts the release package whose firmware/recovery hashes are pinned into the flasher.

MAZPOCKET.LOCAL AFTER v0.03
- Put your phone and Cardputer on the same Wi-Fi.
- Open http://mazpocket.local
- It is the small status/control/diagnostics page, NOT the firmware writer.
- Status is visible immediately.
- Sensitive controls/config require the existing MAZ pairing token.
- Self-test includes speaker, mic, MAZ Host and a small non-destructive SD read/write check.
- Firmware/update sends you to the safe browser flasher.
- If .local does not resolve, use the IP shown by Maz Pocket.
