MAZ POCKET v0.4 — CARDPUTER ADV / M5LAUNCHER

INSTALL
1. Download Maz-Pocket-v0.4-M5Launcher.bin.
2. Put the .bin on the Cardputer microSD card.
3. Boot M5Launcher.
4. Open the SD/local file browser and select the .bin.
5. Choose Install, then launch MAZ Pocket.

IMPORTANT
- This is an app-only M5Launcher image. Do NOT flash it at address 0x0 as a full-device image.
- The SD card can hold lots of firmware/data, but installed apps still use the Cardputer ADV's 8 MB internal flash.
- Keep extra .bin files on SD and swap installed firmware when internal flash is tight.
- Generic ArduinoOTA is intentionally disabled because Launcher may contain several unrelated app partitions.

FIRST WI-FI SETUP
- Open DESK > Connections.
- Press S to scan.
- Pick your Wi-Fi and enter the password.
- MAZ Pocket saves it and automatically reconnects on later boots.
- If Wi-Fi drops, MAZ Pocket retries automatically with bounded backoff.
- A backup/second Wi-Fi can be saved later from mazpocket.local.

WEB DASHBOARD
- Put the Cardputer and phone/PC on the same Wi-Fi.
- Open: http://mazpocket.local
- If .local discovery fails, use the IP shown in DESK > Connections.
- Status is read-only by default. Enter the MAZ Host pairing token to unlock controls.
- The dashboard can open COMM/CAPTURE/OPS/DESK/RECALL/FLOW on the device, control PC media/desktop/lock, test host/storage/speaker, force Wi-Fi reconnect, edit MAZ Host/route/TTS/backup Wi-Fi, reboot and return to M5Launcher.

LOCAL AI
- Preferred Ollama model: lfm2.5-8b-a1b-gpu:latest
- MAZ Host v0.4 defaults to LOCAL routing and this exact model.
- If you already have host/.env from an older version, set:
  MAZ_OLLAMA_MODEL=lfm2.5-8b-a1b-gpu:latest
  MAZ_DEFAULT_ROUTE=local
- v0.4 gives the model a verified MAZ Pocket capability map and low-temperature generation to reduce generic/hallucinated app answers.

HOME
COMM     voice conversation + PC controls
CAPTURE  field capture / voice notes
OPS      Agent Nudge status and nudges
DESK     PC/device controls and connections
RECALL   inbox, notes, snippets and viewer
FLOW     reminders, focus, sprint and tasks

FAST KEYS
- SPACE: COMM / voice
- Ctrl+K: full utility palette
- Ctrl+L: guarded return to M5Launcher

VERSION NAMES
Use v0.1 / v0.2 / v0.3 / v0.4. Older historical preview tags may remain on GitHub only as recovery/history.
