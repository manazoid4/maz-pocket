MAZ POCKET v0.6 — CARDPUTER ADV / M5LAUNCHER

FRESH WINDOWS SETUP — FASTEST PATH
1. Download MAZ-Pocket-v0.6-Install.zip and extract it.
2. Double-click START-HERE.cmd.
3. MAZ Core is installed/updated under %LOCALAPPDATA%\MAZ Core and started automatically.
4. Existing Core .env/config is preserved.
5. If a v0.6 Cardputer is connected over USB, Core address/token pairing is attempted without touching its Wi-Fi credentials.
6. If exactly one removable microSD is connected, setup offers to verify/copy the v0.6 firmware there.
7. Put the SD in the Cardputer, boot M5Launcher, select Maz-Pocket-v0.6-M5Launcher.bin -> Install -> Launch.

START-HERE never formats a drive and never flashes Cardputer partitions directly.

NORMAL PHONE UPDATE — AFTER THE HARDENED PORTAL IS INSTALLED
1. Download Maz-Pocket-v0.6-M5Launcher.bin on the phone.
2. Be on the same LAN as the Cardputer and open http://mazpocket.local.
3. Unlock with the MAZ pairing token.
4. Under STAGE NEXT FIRMWARE choose the .bin and tap VERIFY + STAGE TO SD.
5. Wait for the verified SHA-256 success message.
6. Tap M5LAUNCHER, install the staged image, then Launch.

The upload is staged on SD only. MAZ Pocket checks safe size, ESP image magic and SHA-256. M5Launcher remains the installer/rollback owner.

MANUAL microSD FALLBACK
1. Copy Maz-Pocket-v0.6-M5Launcher.bin to microSD, or double-click INSTALL-MAZ-POCKET.cmd on Windows.
2. Boot M5Launcher, select the .bin, Install, then Launch.

WI-FI — YOU CANNOT GET STRANDED
- Press W from Home, or open CONTROL > WI-FI.
- Scan, choose a network, enter password, save as PRIMARY or BACKUP.
- With no working saved network, MAZ Pocket starts:
    Wi-Fi: MAZ-Pocket-Setup
    password: mazpocket
    browser: http://192.168.4.1
- On normal Wi-Fi use http://mazpocket.local.

MAZ CORE
- START-HERE installs Core to %LOCALAPPDATA%\MAZ Core so deleting the downloaded ZIP does not break startup.
- Core starts at Windows sign-in.
- LOCAL AI route: primary installed Ollama model -> backup installed Ollama model -> clear failure. It never uses cloud.
- AUTO route: primary -> backup -> configured cloud only if both locals fail.
- CLOUD route: configured cloud directly.
- With a v0.6 Cardputer over USB, pair.ps1 can update only Core address/token and leaves known-good Wi-Fi alone.

COMM RESPONSIVENESS
- Recording is immediate and remains durable on-device.
- Session creation, voice upload, optional spoken reply and the small PC command deck run through one bounded background worker.
- A sleeping/unreachable PC should not pin the UI task.
- You can leave COMM while a turn is working; returning to COMM collects the result.
- Failed/offline voice stays in the outbox rather than being discarded.
- v0.6 keeps durable WAV/HTTP as the production voice path. Realtime microphone-frame streaming is deferred until physical ADV testing proves it reliable.

MAZ CORE FROM THE CARDPUTER
- CONTROL > CONTROL CENTER > MAZ CORE.
- See real local projects/branches/dirty state.
- Run safe project jobs: git status, tests, build, fetch, fast-forward pull.
- Builds/tests run on the PC as background jobs so the handheld stays responsive.
- There is no arbitrary remote shell.

LIVE SCREEN / WEB CONTROL
- Open http://mazpocket.local on the same LAN.
- Unlock with the MAZ pairing token.
- Manage Wi-Fi, open device surfaces, control the PC, configure Core, run diagnostics, stage the next app image, reboot/return to Launcher and watch the Cardputer LCD.

MAZ WORKS PRIVATE AI BRIDGE
- /maz-pocket-ai is an unlinked, noindex capability client on Maz Works.
- The public site contains NO private MAZ Core URL or token.
- Supply your own private HTTPS Core URL + bearer token in the browser.
- The page can produce a capability link/access pack for a trusted AI client.
- URL-fragment credentials are not sent to Maz Works; still treat the full link like a password.
- When MAZ Core's optional private GitHub bridge is enabled, an AI with GitHub access can use the private [MAZ CORE] issue queue.
- Core/Cardputer access remains allow-listed; there is no generic remote shell.

IMPORTANT
- The firmware .bin is an app-only M5Launcher image. Do NOT flash it at address 0x0.
- M5Launcher owns firmware installation and rollback.
- SD stores firmware/data; executable apps still share the Cardputer's 8 MB internal flash.
- Generic ArduinoOTA remains disabled.
- Ctrl+K = full command palette. Ctrl+L = M5Launcher hand-back.

PHYSICAL ADV ACCEPTANCE BEFORE CALLING v0.6 FULLY PROVEN
- 30+ minute soak with no reset/watchdog event.
- 20+ COMM turns, including leaving/re-entering COMM mid-request.
- Wi-Fi/Core loss and reconnect.
- phone live-screen polling and verified firmware staging.
- SD absent/unreadable/near-full/interrupted-upload behavior.
- USB Core-only pairing.
- microphone record/playback cycles.
- M5Launcher reinstall + rollback.
- inspect serial [health] and [host-worker] minimum heap/stack/loop measurements.
