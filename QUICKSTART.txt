MAZ POCKET — v0.03 SAFE UPDATE

UPGRADE FROM v0.02
1. Close any older Maz Pocket updater.
2. Extract this ZIP on Windows.
3. Connect the Cardputer ADV with its USB data cable.
4. Run MazPocketUpdater-v0.3.exe.
5. Confirm the title says "Maz Pocket Updater 0.3.2".
6. Click UPDATE MAZ POCKET once.
7. Leave the cable connected until it says Maz Pocket v0.03 ready.

THAT IS ALL
- No FIND button.
- No IP address.
- No host token.
- No M5Launcher screen or boot banner.
- No manual partition commands.

WHAT THE UPDATER DOES
- Reads the Cardputer's live partition table and OTA selection.
- Identifies the selected Maz Pocket slot instead of using a hard-coded offset.
- Verifies the new firmware fits before erasing anything.
- Saves a full recovery copy under %APPDATA%\MazPocket\recovery.
- Never writes the partition table, NVS/settings, M5Launcher, SD data, or sibling apps.
- Writes v0.03 through the ESP32-S3 ROM flasher with --no-stub.
- Reads the new firmware back and requires an exact SHA256 match.
- Requires a v0.03 USB or Wi-Fi boot acceptance response.
- If a write/verify/boot check fails and USB remains reachable, restores the exact previous flash state automatically.

MAZPOCKET.LOCAL AFTER v0.03
- Open http://mazpocket.local while your phone and Cardputer are on the same Wi-Fi.
- The dashboard shows Browser OTA as SAFE only when it can prove a separate Maz-owned OTA partner is available.
- If it says USB ONLY, browser flashing is intentionally disabled so Bruce/M5Launcher/another firmware cannot be overwritten.
- Browser OTA requires the existing MAZ pairing token.
- If .local does not resolve, use the IP shown by Maz Pocket.

DEVICE
- Home: COMM / LOG / OPS.

- Ctrl+L: guarded M5Launcher hand-back.
