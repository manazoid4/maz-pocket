MAZ POCKET v0.7 — FIELD QUICKSTART
=================================

WHAT TO DOWNLOAD
----------------
Laptop/client only:   MAZ-Core-v0.7.zip
Cardputer only:       MAZ-Cardputer-v0.7.zip
Everything together: MAZ-Pocket-v0.7-Install.zip

The Cardputer ZIP contains the app-only M5Launcher firmware. M5Launcher owns install and rollback. Do NOT flash the app .bin at address 0x0.

FIRST START / WINDOWS
---------------------
1. Extract MAZ-Pocket-v0.7-Install.zip.
2. Double-click START-HERE.cmd.
3. MAZ Core installs/updates in the normal per-user location and preserves an existing .env.
4. Install/launch Maz-Pocket-v0.7-M5Launcher.bin using M5Launcher.

HOME
----
NOW shows one useful priority, not a dashboard.
1 / 2 / 3 / 4 = your four quick actions.
Fn + 1/2/3/4 = cycle that slot to another safe action.
Default: 1 TALK / 2 NOTE / 3 LAP / 4 BEAM.

GLOBAL
------
Fn + Space = Context Ask: hold, speak about the current screen/item, release.
Fn + F     = FIELD mode on/off.
Ctrl + K   = command palette.
Ctrl + L   = return to M5Launcher.
Fn + M on Home = harmless retro Easter egg.

BEAM
----
Pocket -> laptop:
CONTROL -> BEAM -> N -> type -> ENTER. If Core is offline it stays in Outbox and sends later.

Laptop -> Pocket:
Copy text or a URL, then run BEAM-TO-POCKET.cmd from the MAZ Core folder. You can also POST through MAZ Core /beam/to-pocket.

OUTBOX
------
Failed/offline COMM recordings, Context Ask turns and outgoing Beams are kept. MAZ Pocket retries the oldest queued work automatically after Wi-Fi/Core returns. Home NOW shows the queue count.

LAPTOP STATUS
-------------
CONTROL -> LAPTOP. It shows a small on-demand CPU/RAM/GPU/VRAM/battery/Ollama snapshot. R refreshes. FIELD mode reduces refresh frequency.

SHIFT
-----
FLOW -> SHIFT CLOCK -> ENTER start/stop. Home NOW shows elapsed shift time. Completed elapsed time is saved locally.

LOCAL AI PROFILE
----------------
SMART = default balanced mode (ordinary turns 4K context, 5m warm model).
SAVE  = unload local model after each response.
FAST  = keep model warm longer.
Set MAZ_AI_PROFILE=smart|save|fast in MAZ Core .env. Existing LOCAL/AUTO/CLOUD routing stays separate.

PHONE FIRMWARE STAGING
----------------------
On the same LAN open http://mazpocket.local, unlock, choose a compatible M5Launcher app .bin, verify/stage to SD, then return to M5Launcher to install it. MAZ Pocket does not self-flash.

BEFORE A WEEK IN THE FIELD
--------------------------
- Confirm Wi-Fi + MAZ Core pairing.
- Try one normal COMM turn and one Context Ask.
- Turn Wi-Fi off, record a voice turn, restore Wi-Fi, confirm OUTBOX clears.
- Beam text in both directions.
- Open LAPTOP and check CPU/RAM/GPU/VRAM.
- Start/stop SHIFT CLOCK.
- Confirm Ctrl+L returns to M5Launcher and v0.6 rollback still exists.

See RELEASE_NOTES.md and docs/V070-FIELD.md for the full validation gate.
