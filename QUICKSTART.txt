MAZ POCKET — QUICK START

FIRST INSTALL / RECOVERY
1. Extract this ZIP on Windows.
2. Run MazPocketUpdater-v0.3.exe.
3. Connect Cardputer ADV by USB data cable.
4. Use USB UPDATE.
5. Use PAIR once if Wi-Fi/MAZ Host is not already configured.

NORMAL UPDATE AFTER PAIRING
- Same Wi-Fi: run the updater -> FIND -> WI-FI UPDATE.
- After this build is installed you can also open http://mazpocket.local,
  enter the MAZ pairing token, choose the new maz-pocket-app.bin under
  Browser OTA, and upload it directly.

MAZPOCKET.LOCAL
- Device-hosted local dashboard, not a public Internet site.
- If the .local name does not resolve, use the Cardputer's numeric IP.
- Configure Wi-Fi/host routing, run mic/speaker/host tests, inspect status,
  upload firmware, reboot, or safely request M5Launcher hand-back.

DEVICE
- Home: COMM / LOG / OPS.
- Ctrl+K: all utilities + Snake / Hyperdrive / Beam.
- Ctrl+L: safe M5Launcher hand-back.

IMPORTANT
- Browser and Wi-Fi OTA require the existing MAZ pairing token.
- Keep the PC and Cardputer on the same LAN for local OTA.
- This CI build is compile/test verified; physical mic/speaker/OTA/Launcher
  acceptance still needs the real Cardputer.
