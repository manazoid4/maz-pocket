MAZ POCKET v0.4 — CARDPUTER ADV / M5LAUNCHER

INSTALL
1. Download Maz-Pocket-v0.4-M5Launcher.bin.
2. Put the .bin on the Cardputer microSD card.
3. Boot M5Launcher.
4. Open the SD/local file browser and select the .bin.
5. Choose Install, then launch MAZ Pocket.

IMPORTANT
- This is an app-only M5Launcher image. Do NOT flash it at address 0x0 as a full-device image.
- The 64 GB SD card can hold lots of firmware files/data, but installed apps still use the Cardputer ADV's 8 MB internal flash.
- Keep extra .bin files on SD and swap installed firmware when internal flash is tight.
- Generic ArduinoOTA is intentionally disabled because Launcher may contain several unrelated app partitions.

FIRST WI-FI SETUP
- Open DESK > CONNECTIONS.
- Press S to scan.
- Pick your Wi-Fi and enter the password.
- MAZ Pocket saves it and automatically reconnects on later boots.
- A second saved network is supported by the networking layer.
- If Wi-Fi drops, MAZ Pocket retries automatically with bounded backoff.

WHEN CONNECTED
- Open http://mazpocket.local from a phone/PC on the same network.
- Use it for status, diagnostics, MAZ Host configuration, speaker/mic/storage checks and Launcher hand-back.

HOME
COMM     voice conversation + PC controls
CAPTURE  field capture / voice notes
OPS      Agent Nudge status and nudges
DESK     PC/device controls and connections
RECALL   inbox, notes, snippets and viewer
FLOW     reminders, focus, sprint and tasks

FAST KEYS
- SPACE: COMM / voice
- Ctrl+K: full utility palette
- Ctrl+L: guarded return to M5Launcher
