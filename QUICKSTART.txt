MAZ POCKET v0.5 — CARDPUTER ADV / M5LAUNCHER

FASTEST SAFE INSTALL
1. Download MAZ-Pocket-v0.5-Install.zip from the build/release assets and extract it.
2. Put the Cardputer microSD card in the Windows PC.
3. Double-click INSTALL-MAZ-POCKET.cmd.
4. It launches the verified copy helper, validates the ESP32 app image, refuses fixed disks, copies only the MAZ Pocket .bin, then verifies SHA-256.
5. Safely eject the card, boot M5Launcher, select Maz-Pocket-v0.5-M5Launcher.bin, Install, then Launch.

If the .cmd launcher is blocked by local policy, run .\install-to-sd.ps1 from PowerShell instead.

MANUAL CARDPUTER INSTALL
1. Copy Maz-Pocket-v0.5-M5Launcher.bin to microSD.
2. Boot M5Launcher, select the .bin, Install, then Launch.

WI-FI — YOU CANNOT GET STRANDED NOW
- Press W from Home, or open CONTROL > WI-FI.
- Scan, choose a network, enter password, save as PRIMARY or BACKUP.
- With no working saved network, MAZ Pocket starts:
    Wi-Fi: MAZ-Pocket-Setup
    password: mazpocket
    browser: http://192.168.4.1
- On normal Wi-Fi use http://mazpocket.local.

MAZ CORE ON THE WINDOWS PC
1. Extract MAZ-Core-v0.5.zip.
2. Right-click PowerShell in that folder if you want the firewall rule created automatically.
3. Run: .\install-core.ps1
4. It installs/starts MAZ Core, selects lfm2.5-8b-a1b-gpu:latest, finds local projects, enables startup and prints the PC address + MAZ token.
5. On Cardputer open CONTROL > MAZ CORE if pairing details need changing.

MAZ CORE FROM THE CARDPUTER
- CONTROL > CONTROL CENTER > MAZ CORE.
- See real local projects/branches/dirty state.
- Run safe project jobs: git status, tests, build, fetch, fast-forward pull.
- Builds/tests run on the PC as background jobs so the handheld stays responsive.
- There is no arbitrary remote shell.

LIVE SCREEN / WEB CONTROL
- Open http://mazpocket.local on the same LAN.
- Unlock with the MAZ pairing token.
- You can manage Wi-Fi, open device surfaces, control the PC, configure Core, run diagnostics, reboot/return to Launcher and watch the Cardputer LCD at ~2 FPS.
- Cardputer ADV has no built-in camera. This release streams the LCD; camera video needs external camera hardware.

MAZ WORKS PRIVATE CONSOLES
- /maz-core is the private human Core console.
- /maz-pocket-ai is the private AI/Cardputer capability-link client.
- Both are noindex and ship with NO private Core URL or token.
- The AI bridge can create a capability URL whose secret is kept in the URL fragment, so Maz Works never receives it. Treat the full capability URL like a password and rotate the MAZ token if it is exposed.
- Agents that support authenticated HTTP can use the copied AI access pack to reach the documented Core/Cardputer allow-list.
- When MAZ Core's private GitHub bridge is enabled, /maz-pocket-ai can also copy a ChatGPT-specific GitHub bridge prompt using the configured private queue repository.
- install-core.ps1 attempts private Tailscale Serve setup when Tailscale is already installed.

CHATGPT -> LOCAL PC / CARDPUTER
- For ChatGPT with GitHub access, the existing private GitHub bridge remains the safest asynchronous route to MAZ Core.
- For AI agents that can call authenticated HTTPS directly, use the Maz Works /maz-pocket-ai capability link/access pack.
- Core exposes Cardputer status and live LCD through /core/cardputer/status and /core/cardputer/screen; do not expose a generic remote shell.

IMPORTANT
- The firmware .bin is an app-only M5Launcher image. Do NOT flash it at address 0x0.
- SD stores firmware/data; executable apps still share the Cardputer's 8 MB internal flash.
- Generic ArduinoOTA remains disabled; M5Launcher owns firmware installs safely.
- Ctrl+K = full command palette. Ctrl+L = M5Launcher hand-back.
