MAZ Pocket

Firmware for the M5Stack Cardputer ADV. Flash it from this page — no app, no toolchain.

Keep M5Launcher — recommended

Download the app-only binary, then install it from M5Launcher using WUI or a FAT32 microSD card. Launcher, Bruce, Nemo and your other installed apps stay in place.

Download MAZ Pocket app binary

Replace the whole device

This removes M5Launcher and every installed app. Use it only when you want MAZ Pocket to own the device.

This browser cannot talk to serial devices. Use desktop Chrome or Edge. Serial access needs a secure page (https or localhost). Chrome or Edge, desktop, USB-C data cable.

What happens

  1. Plug the Cardputer into USB-C and press Connect & flash.
  2. Pick the serial port in the browser dialog.
  3. Wait about a minute. If connection fails, unplug it, hold G0, reconnect USB-C, then try again.
  4. It reboots into MAZ Pocket.

This writes a full image: bootloader, partition table and app. It replaces whatever is on the device, including M5Launcher.

After flashing

  • Capture, Focus, Sprint, Decision and reminders work offline.
  • For Talk and Nudge, run host/setup.ps1 once, then host/run.ps1.
