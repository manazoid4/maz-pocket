# Final demonstration shot list

Use the final flashed commit only. Keep the Cardputer and PC visible together whenever possible. Record the screen clearly enough to read status and receipts.

1. **Opening, 8 seconds:** show the real Cardputer four-tile Home. Say the one-line project description.
2. **Connection chain, 12 seconds:** point from human to Cardputer to Wi-Fi indicator to MAZ Core on the PC, then back to the Cardputer result.
3. **CALL, 25–40 seconds:** use a real human voice. Show LISTENING, release, MAZ Core activity, actual provider label and the returned answer. Include speaker playback only if it passes.
4. **Brain Dump, 20–30 seconds:** record a short idea, send it, then show the structured result.
5. **PLAN, 20 seconds:** type a small task, show responsive loading and the result. State that PLAN does not execute.
6. **PC ACTION, 25 seconds:** request "create a note saying element14 connection proven." Show the proposal, press Enter on the Cardputer, show the new Notepad window and show the receipt returning to the device. Do not expose private files or notifications.
7. **CONTROL, 10 seconds:** show truthful Wi-Fi/Core/route status.
8. **Closing, 8 seconds:** repeat the connection chain and show the project name.

Before filming: enable Do Not Disturb; use synthetic, non-client text; hide tokens, Wi-Fi credentials, usernames, unrelated browser tabs and private notifications. Do not edit around a failed action so it appears successful. Record a fresh take after fixing the failure.
